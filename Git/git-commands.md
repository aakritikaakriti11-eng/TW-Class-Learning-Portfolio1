
# Git Commands Practical

## 1. Check Git Version

git --version

## 2. Configure Git Username

git config --global user.name "Your Name"

## 3. Configure Git Email

git config --global user.email "your-email@example.com"

## 4. Check Configuration

git config --list

## 5. Initialize Repository

git init

## 6. Check Repository Status

git status

## 7. Add Files

git add .

## 8. Commit Changes

git commit -m "Initial commit"

## 9. View Commit History

git log --oneline

## 10. View Branches

git branch

## 11. Create New Branch

git branch feature

## 12. Switch Branch

git switch feature

## 13. Merge Branch

git switch main
git merge feature

## 14. View Differences

git diff

## 15. Connect Remote Repository

git remote add origin REPOSITORY_URL

## 16. Push Changes

git push -u origin main

## 17. Pull Changes

git pull origin main

## 18. Clone Repository

git clone REPOSITORY_URL
