
# Git Documentation

## Introduction

Git is a distributed version control system used to track changes in files and manage project versions.

## Features of Git

- Tracks changes in files.
- Maintains project history.
- Supports branching and merging.
- Allows collaboration.
- Helps restore previous versions.

## Important Git Commands

| Command | Purpose |
|---|---|
| git --version | Checks Git version |
| git config | Configures Git settings |
| git init | Initializes a repository |
| git status | Shows repository status |
| git add . | Stages all changes |
| git commit -m "message" | Saves changes |
| git log | Displays commit history |
| git branch | Lists branches |
| git switch | Switches branches |
| git merge | Merges branches |
| git clone | Copies a repository |
| git push | Uploads changes |
| git pull | Downloads and integrates changes |

## Advantages of Git

- Efficient version control.
- Tracks project history.
- Supports teamwork.
- Makes project management easier.

## Conclusion

Git is an essential tool for managing source code and tracking changes throughout software development.
