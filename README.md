## Topics Covered

### 1. LaTeX

LaTeX is a document preparation system used to create professional documents, reports, research papers, mathematical equations, and tables.

[Open LaTeX Documentation](LaTeX/README.md)

### 2. Beamer

Beamer is a LaTeX document class used to create professional presentations and slides.

[Open Beamer Documentation](Beamer/README.md)

### 3. Doxygen

Doxygen is a documentation generation tool that creates software documentation from specially formatted comments in source code.

[Open Doxygen Documentation](Doxygen/README.md)

### 4. Google Docs

Google Docs is an online word-processing application used to create, edit, format, and share documents.

[Open Google Docs Documentation](Google-Docs/README.md)

### 5. Git

Git is a distributed version control system used to track changes in files, manage project versions, and collaborate with others.

[Open Git Documentation](Git/README.md)

### 6. GitHub

GitHub is an online platform used to host Git repositories, manage projects, and collaborate with other developers.

[Open GitHub Documentation](GitHub/README.md)
